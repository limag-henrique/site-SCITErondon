# Fontes documentais sanitizadas

Esta pasta contém somente derivados necessários à auditoria científica:

- `notas_metodologicas_anonimizadas.pdf`: notas metodológicas parafraseadas, limitadas à classificação das interfaces, fricção do esquema e justificativa do caso sentinela;
- `notas_cientificas_anonimizadas.pdf`: matriz de argumentos e referências científicas reaproveitáveis, sem proveniência identificável.

Não foram copiados os originais porque continham nomes, contatos, afiliações, identificadores persistentes, instituições, itinerários, microterritórios ou descrições sensíveis. Versões anteriores também foram excluídas porque este repositório é exclusivamente um pacote de dados e materiais suplementares.
